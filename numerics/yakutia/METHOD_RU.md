# Границы, свидетели и воспроизведение

Единицы: кВт, кВт·ч, шаг 1 ч; E — запас в выходной электрической энергии, η — эффективность зарядного пути в таком представлении. При фиксированной мощности r нормализация даёт S_t=max(x_t+r,0), q_t=max(−x_t−r,0). Решатель использует неотрицательные c,d,e,ℓ, условия ∑c≤S, ∑d+ℓ=q, e_it=e_i,t−1+η_i c_it−d_it, покомпонентные паспортные ограничения и e_i,−1=e_i,T−1. Заряд разрешён при S>0, разряд — при q>0. Источник включён в S: заряд от источника разрешён.

Для q_t>0 вводится z_t∈{0,1}, ℓ_t≤q_t z_t. Норма H: ∑z≤H. Циклическая D: сумма z в каждом окне D+1 не превосходит D. Окна, содержащие q_t=0, уже удовлетворяют ограничению и пропускаются. Принятый свидетель проверяется прямыми балансами отдельным `summarize.py`, включая ℓ вне разрешённой маски, целочисленность из журнала и циклическую длину серии. Час с z=1 и ℓ=0 допустим; поэтому подсчёт z — консервативный верхний предел часов фактического дефицита.

Начальная верхняя граница — источник без накопителя. Для H это (H+1)-я наибольшая величина max(−x,0), для D — максимум минимумов max(−x,0) по всем циклическим окнам D+1. Совместная граница — максимум этих двух мощностей. Это явный допустимый режим c=d=e=0, ℓ=max(−x−r,0).

Нижние границы строятся из необходимых условий. В каждой непрерывной серии q>0 заряд отсутствует, поэтому вся доступная энергия не превосходит ∑E, а полностью обслуживаемый час требует q_t≤∑Pd. Минимальное число потерянных часов в такой энергетической релаксации получается обслуживанием наименьших q_t до исчерпания ∑E; сумма минимальных потерь по сериям не должна превосходить H. Дополнительно, по всему циклу энергия самых дешёвых T−H полностью обслуживаемых часов не превосходит η_max∑S. Эти условия оптимистичны: полный начальный запас разрешён в каждой серии независимо, ограничения зарядной мощности и неоднородность устройств ослаблены. Поэтому их нарушение — корректный сертификат невозможности, но выполнение не доказывает допустимость.

Для D в каждой серии динамическая программа выбирает полностью обслуживаемые часы с промежутками не более D+1, минимизируя сумму q_t. Первый обслуживаемый час не позже D-го, последний не раньше длины серии−D−1; часы q_t>∑Pd выбирать запрещено. Минимальная требуемая энергия каждой серии не превосходит ∑E, сумма минимумов по всем сериям — η_max∑S. Если весь цикл имеет строго положительный q, заряд отсутствует и при свободной цикличности разряд за цикл нулевой: H<T или D<T невозможны.

Бискекция необходимых условий даёт нижнюю границу; только статус infeasible MILP повышает её далее. Неизвестный статус ничего не исключает. Любой найденный при остановке режим принимается только после проверки допустимости. Итог Γ находится в [max(0,L_joint−max(U_H,U_D)), max(0,U_joint−max(L_H,L_D))]. Включения между нормами и фактические маски сохранённых режимов дополнительно сужают интервалы; происхождение каждой изменённой границы находится в `derived_results.json`. Для H≤D совместное множество совпадает с H-множеством и Γ=0 точно, независимо от ширины вычислительных интервалов.

Команды из корня репозитория:

```sh
PYTHONDONTWRITEBYTECODE=1 python numerics/yakutia/run.py
PYTHONDONTWRITEBYTECODE=1 python numerics/yakutia/check_small.py
PYTHONDONTWRITEBYTECODE=1 python numerics/yakutia/summarize.py
```

Первый запуск перезаписывает результаты ограниченного прохода; ширина интервалов зависит от производительности машины. Проверка `check_small.py` сравнивает новую разреженную формулировку с прежним независимым кодом на 30 фиксированных малых случаях. Положительных научных результатов Γ>0 эта проверка сама по себе не доказывает. `results.json` хранит исходные границы/статусы, `derived_results.json` — их строгую постобработку, `table.csv` — конечные числовые интервалы, `catalogues.json` — сопоставление с тремя каталогами по одному агрегату.
